# 综合日语1 单词数据整理说明（review-notes）

本文件记录「综合日语1 → 单词」两个范围（期中 1—6 课、期末 7—15 课）词条数据的整理口径、数量汇总、重复合并情况、纠错前后对照，以及全部待核实（`needs_review`）词条。

整理过程中未对任何项目代码做修改，也未生成选择题或干扰选项。

两个 JSON 均为 UTF-8 编码、`json.load` 可直接解析，顶层结构一致：

```json
{
  "category": "综合日语1",
  "subcategory": "单词",
  "scope": "midterm | final",
  "scopeLabel": "期中范围（1—6课） | 期末范围（7—15课）",
  "idPrefix": "japanese1-mid- | japanese1-final-",
  "note": "整理口径说明",
  "sources": [ { "file": "...", "role": "...", "structure": "..." } ],
  "entryCount": 326,
  "entries": [ /* 每条字段见下 */ ]
}
```

每条词条字段固定为 11 项，顺序一致：

`id`、`scope`、`original`、`word`、`reading`、`meaning`、`partOfSpeech`、`type`、`sources`、`status`、`notes`

- `original` 保留原文写法，不被规范化字段覆盖；
- `sources` 为数组，同一词条在原文多处出现时逐条列出（文件名 / 章节或表名 / 条目位置），合并时不丢位置；
- `type` 取值为「普通词汇 / 专有名词 / 固定表达 / 数字日期」；
- `status` 取值为 `ready` 或 `needs_review`。

## 四、重复合并情况

### 4.1 期中：759 行 → 326 条

- **第一节与第二、三节合并**：261 条词条同时挂靠第一节（假名）与第三节（中文）两个位置，其中 155 条再挂靠第二节（汉字）位置，故绝大多数词条 `sources` 为 2—3 条。`sources` 条数为 2 的 115 条、为 3 的 155 条，合计 **272 条为多位置合并**；单位置 54 条。

- **第四节内部「平假名↔汉字」两栏重复合并**（11 条，各 2 条 sources）：`手洗い`（0262）、`円`（0270）、`下さい`（0271）、`売り場`（0272）、`何階`（0274）、`何月`（0282）、`何日`（0283）、`誕生日`（0284）、`普通`（0286）、`急行`（0287）、`特急`（0288）。

- **刻意不合并**（同字但含义/义项不同）：`こちら` —— japanese1-mid-0012（第 1 组「人称代词 & 称呼」第 12 项，"这位／这边（礼貌）"）与 japanese1-mid-0249（第 19 组「方位 & 交通」第 4 项，"这边（礼貌）"），两条 `notes` 互相指明未合并的原因。

### 4.2 期末：477 行 → 384 条

- 合并后 `sources` 为 2 条的共 **93 条**，其余 291 条为单来源。
- 合并主因：「假名表」虽然表名写着「除上面四个表中的词汇以外，剩下的」，但实际把动词表、外来词表、形容词表、日本汉字表中的大量词条又重复列了一遍，造成 93 条跨表重复（如 `作る`、`速い`、`暇`、`いい`、`ほしい`）。
- **多写法合并**：同一读音在两张表里汉字写法不同（形容词表常只写假名，假名表写「汉字（假名）」），共 **38 条**做了「word 取含汉字的写法、reading 取假名」的合并，并在 `notes` 中注明「原文分别写作「A」／「B」，已合并为标准写法「C」」。典型例子：
  - `作る／造る`（japanese1-final-0165）—— 原文即为「作る／造る」两种写法同格并列，`original` 记为 `作る／造る（つくる）`；
  - `速い／早い`（japanese1-final-0267）—— `original` 为 `はやい／速い／早い（はやい）`，`word` 为 `速い／早い`；
  - `暖かい／温かい`（japanese1-final-0270）、`遅い`（0268）、`小さい`（0288）、`暇`（0294）等。
- **释义措辞不同的同义合并**：`暇`（japanese1-final-0294）在形容词表作「有时间、有空儿」、在假名表作「有空」，判定为同一含义，已合并并在 `notes` 记录两处措辞。
- **刻意不合并**：
  - `もう`（japanese1-final-0305「再～、还～」 vs japanese1-final-0364「已经」）—— 同形不同义，保留 2 条，各自 `sources` 指向假名表第 4 行、第 135 行；
  - `町`（japanese1-final-0115「まち／市镇、街道」 vs japanese1-final-0136「みどりちょう／绿町（虚构的城市）」）—— 同字不同读，保留 2 条，0136 的 `notes` 注明「与「町（まち）」同字不同读，二者不是同一条目，未合并」；
  - `研究`／`研究する`、`結婚`／`結婚する`、`散歩`／`散歩する`、`買い物`／`買い物する`、`食事`／`食事する`、`コピー`／`コピーする` —— 名词（名・動Ⅲ）与动词（動Ⅲ）词形不同，属两条不同词条，未合并。

### 4.3 跨范围重复

用户要求「两个范围之间重复的词可以各自保留」，因此**未做跨范围合并**。实测两 scope 的 `word` 交集仅 5 个：`あれ`、`すみません`、`どちら`、`テーブル`、`～から`（期中 324 个不同 word、期末 382 个不同 word）。这 5 个词在两个文件中各自独立保留，含义与词性也按各自原文。

### 5.1 一律未做的「自动修改」

以下情况均**保持原文、不做替换**，只记录或标注：

1. **纯假名 / 片假名词条不虚构汉字**。如期中 `します`、`あります`、`～からきました`、`おはようございます`、`こんにちは`、`そうですか`、`はい`、`いいえ` 等，`word` 与 `original` 相同，`notes` 写明「原文即假名，未补汉字」；期末 122 条「原文以假名给出」的词条同样未补汉字。
2. **动词形式不作转换**。原文为ます形的，`word` 一律保留ます形（期中 `partOfSpeech` 记为「動」的共 22 条，其中 21 条 `notes` 明确写有「原文为ます形，按要求保留」，如 japanese1-mid-0199 `みます` → `見ます`；另一条 `～からきました`（0206）同为ます形，措辞为「原文为纯假名+「～」并带ます形」）；期末「动词表」原文即辞书形，也一律保留辞书形，未做形式统一。
3. **数字条目未改写成阿拉伯数字**（如 `一日`/`二日`/`二十日` 等保持原文汉字写法，`meaning` 里补「1 号/2 号/20 号」）。
