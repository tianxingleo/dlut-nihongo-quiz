# 更新公告：综合日语3 第37–43课单词题修复

## 一句话

修复了综合日语3单词题库中「题目语言与题型不匹配」的问题：没有汉字写法的词，不再强行出「选汉字 / 选假名」题，改为「选中文翻译」题。

## 变更说明

本次修复共涉及 **103 个词条 / 170 道题**，题库总题数不变（738 道）。

- **片假名外来语**（ポルトガル、オリンピック、テスト、マラソン、アパート 等）与**平假名惯用词/固定表达**（しかし、いただきます、うまい、まずい 等）原本没有汉字写法，却生成了「选汉字」题。现改为：
  - A 题：给假名 → 选中文释义（如 `ポルトガル` → 葡萄牙）。
  - B 题：给中文 → 选假名读音（如 `葡萄牙` → ポルトガル）。
  - 题型标签「选汉字 / 选假名」保持不变。
- 部分「选汉字」题中混入的假名干扰项（如 `キロ`、`しかし`、`おばさん`），已替换为对应中文释义，其余汉字选项保持不变。
- 授受动词 `あげます` 的翻译由「调高、提高、改善」补正为「给」。

## 对刷题的影响

- 修复后的题干、选项、答案、解析均同步更新；历史答题记录按题目 `id` 关联，不受影响。
- 词条 ID、题量、课次分组（第37–43课）均保持不变。

- 运行时题库 `public/japanese3-question-bank.json` 已更新；来源存档 `data/raw/japanese3/vocabulary-37-43.md` 保持原样（该题库按约定直接维护 JSON）。
