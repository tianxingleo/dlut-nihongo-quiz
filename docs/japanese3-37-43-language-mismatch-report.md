## 3. 根因归纳

1. **片假名外来语无汉字写法**：如 ポルトガル、オリンピック、テスト、タオル、マラソン、ローン、アパート、パンフレット 等。生成器仍按「假名→汉字」「汉字→假名」双方向出题，导致 A 题四个选项全是片假名、B 题题干是片假名。
2. **平假名惯用词/固定表达无常用汉字写法**：如 しかし、いけない、きちんと、つきます、ぶつかります、びっくりします、いただきます、くださいます、やります、うまい、まずい、つまらない、すると、わあ 等，同样被生成双向题。
3. **「选汉字」题干扰项混入假名词**：正确项本身是汉字词，但干扰池里混入了无汉字词（如 キロ、ハンカチ、しかし、おばさん、おじ 等），造成单个选项语言与题型不符。

> 注：本次未发现「给假名选汉字题干出现汉字」或「给汉字选假名选项出现汉字」两类情况（均为 0）。
