## 维护方式

权威可编辑源：`data/raw/jp1-mid24/reviewed-questions.json`。

```sh
npm run parse:japanese2-midterm
npm run generate:meta
npm run test:japanese2-midterm
npm run audit:banks
```

脚本同时生成网页 JSON 和便于阅读的 Markdown 存档；不要直接修改这两个生成文件。保留既有内部分类 `jp1-mid24` 和可确认的旧题ID，避免把原进度误归到另一道题；删除的重复条目不会自动迁移历史记录。
