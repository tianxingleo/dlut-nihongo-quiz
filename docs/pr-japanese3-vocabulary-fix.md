# PR：综合日语3 第37–43课单词题 语言与题型不匹配修复

## 概述

综合日语3单词题库（`public/japanese3-question-bank.json`）中，一批词条没有汉字写法（片假名外来语、平假名惯用词/固定表达），却仍被生成了「给假名选汉字 / 给汉字选假名」双向题，导致：

- 「给假名选汉字」题出现 4 个选项全是假名（无汉字可选）；
- 「给汉字选假名」题的题干其实是纯假名（不是汉字）；
- 部分「选汉字」题的干扰项混入了假名词。

本次按「无汉字写法 → 直接翻译为中文」的规则修复，纯数据改动，不改代码、不改题型标签。

## 变更内容

### 1. 无汉字写法词条（67 个，134 题）改为中文翻译双向题

- A 题：题干前缀 `假名 → 汉字｜X` → `假名 → 中文｜X`，选项/答案由假名/汉字改为 4 个中文释义。
- B 题：题干前缀 `汉字 → 假名｜X` → `中文 → 假名｜释义`，选项保持假名。
- `subType` 保持 `kana-to-kanji` / `kanji-to-kana`，标签保持「选汉字 / 选假名」，未新增题型。

### 2. 选汉字题混入的假名干扰项（36 题）

把干扰项中的假名词替换为其中文释义，保留其余汉字选项，题型仍为「选汉字」。

### 3. 授受动词 あげます 义项补正

`あげます` 在授受语境下由「调高、提高、改善」补正为「给」（涉及 w41-001/002/003）。
